# Stock & Crypto Analyzer

A Python-based analyzer that helps evaluate stocks and cryptocurrencies using
KPIs, technical indicators, and news sentiment.

## Features (planned)
- Stock & crypto market data ingestion
- KPI calculation engine
- News sentiment analysis
- REST API (FastAPI)
- Web interface

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- SQLite / PostgreSQL
- Free market & news APIs
